# Palette

Palette is an online art gallery showcasing an exceptional collection of original paintings, drawings, sculptures and photography by Calvin art students. This is a platform to exhibit their creative works and draw inspiration from a diverse community of artists and creators. 

Website is hosted in Firebase Hosting and deployed to this link: https://palette-e3d2a.web.app
